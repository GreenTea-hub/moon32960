# moon32960 protocol notes

本文记录本仓库实际实现到的帧格式与字段布局，并明确标出**尚未按标准正文核对**的地方。
标准文本受版权保护，仓库不摘录原文；这里的描述用于说明代码行为，不构成标准。

## 1. 帧格式（已实现）

```
+--------+----------+----------+-------------------+----------+----------+---------+
| start  | command  | response | VIN (17B, ASCII)  | encrypt  | length   | payload |
| 2B     | 1B       | 1B       |                   | 1B       | 2B (BE)  | N B     |
+--------+----------+----------+-------------------+----------+----------+---------+
```

- 起始符：`0x23 0x23`（`##`）；
- 总长度 = 24 + N；`length` 与实际 payload 长度不一致时抛出 `BadLength`；
- VIN 校验：17 位、ASCII、不含 `I`/`O`/`Q`；
- 长度字段按**大端**解释（待核对项 #1）。

## 2. 命令标识（已实现）

| 值 | 语义 | 方向 |
|---|---|---|
| 0x01 | 车辆登入 | 终端 → 平台 |
| 0x02 | 实时信息上报 | 终端 → 平台 |
| 0x03 | 补发信息上报 | 终端 → 平台 |
| 0x04 | 车辆登出 | 终端 → 平台 |
| 0x05 | 平台登入 | 平台 → 平台 |
| 0x06 | 平台登出 | 平台 → 平台 |
| 0x07 | 心跳 | 终端 → 平台 |
| 0x08 | 终端校时 | 平台 → 终端 |
| 0x80 | 平台下行 | 平台 → 终端 |

未列出的取值保留为 `Unknown(n)`，解码不失败。

## 3. 应答标志 / 加密方式（已实现）

应答标志：`0x01` 成功、`0x02` 失败、`0x03` VIN 重复、`0xFE` 命令不识别、`0xFF` 无效。

加密方式：`0x01` 明文、`0x02` RSA、`0x03` AES128、`0xFE` 异常、`0xFF` 无效。
**实现只透传该字节，不执行加解密**（待实现项）。

## 4. 时间编码（已实现，字段语义待核对）

6 字节，每字段 1 字节，年份 = 2000 + byte。实现校验：年 2000..2099、月 1..12、日 1..31、时 0..23、分/秒 0..59。

## 5. 数据单元布局（本仓库字典布局，待核对）

### 5.1 车辆登入（8 字节）

```
time(6) | sequence(2B BE)
```

### 5.2 车辆登出（8 字节）

```
time(6) | sequence(2B BE)
```

### 5.3 实时上报

```
time(6) | item*
item := type(1B) | length(1B) | body(length B)
```

已实现的信息项：

| type | 名称 | body 布局 |
|---|---|---|
| 0x01 | 整车状态 | status(1) charge(1) speed(1) soc(1) voltage(2) odometer(3) = 9B |
| 0x05 | 位置 | status(1) longitude(4B i32, 1e6 缩放) latitude(4B i32, 1e6 缩放) = 9B |

其余信息项（电机、燃料电池、发动机、极值、报警、储能电压/温度/极值）只保留类型枚举，解析时返回 `Payload("unsupported info type ...")`。

## 6. 网关路由（已实现）

| 命令 | 未知 VIN | 已知 VIN |
|---|---|---|
| 车辆登入 | 建会话 + 登入 → `LoginAccepted` | 重登 → `LoginResumed` |
| 实时上报 | `Rejected` | 计数 + `ReportAccepted` |
| 补发上报 | `Rejected` | 补发计数 + `ReportAccepted` |
| 心跳 | `Rejected` | `HeartbeatAccepted` |
| 车辆登出 | `Rejected` | 关闭会话 + `LogoutAccepted` |
| 其它 | `Rejected("unsupported command: ...")` | 同左 |

## 7. 错误类型（已实现）

`FrameError`：`InvalidStart`、`TooShort`、`BadCommand`、`BadResponseFlag`、`BadEncryption`、`BadVin`、`BadLength`、`BadTime`、`Payload`。
所有错误都携带定位信息（期望/实际长度、VIN、字段值），CLI 与测试可直接断言。
