# 协议实现对照

本文件是速查表，完整的覆盖矩阵、兼容性终点与未覆盖项见 [CONFORMANCE.md](CONFORMANCE.md)，三个可复现案例见 [EXAMPLES.md](EXAMPLES.md)。

## 报文结构

```
[起始符 2B "##"][命令单元 1B][应答标志 1B][VIN 17B][加密方式 1B][数据单元长度 2B 大端][数据单元 NB][校验码 1B]
```

- 帧总长 = 24 + N + 1；
- 校验码为 BCC 异或，范围从命令单元首字节到数据单元末字节；
- WORD / DWORD 均为大端。

## 异常与无效码

| 宽度 | 异常 | 无效 |
|---|---|---|
| BYTE | 0xFE | 0xFF |
| WORD | 0xFFFE | 0xFFFF |
| DWORD | 0xFFFFFFFE | 0xFFFFFFFF |

换算函数遇到异常/无效码返回 `None`，不参与算术。

## 平台处理规则（两套，按 `Scope` 区分）

### 车端（附录 B，资料性）

| 上行命令 | 校验正确 | 校验失败 |
|---|---|---|
| 0x01 登入 | 应答 `01` | 忽略，不应答 |
| 0x01 VIN 已在线 | 应答 `02`（2016 口径）；`03` 需 `ResponseProfile::Extended` | — |
| 0x02 实时 | 计数，**不应答** | 应答 `02`（终端 1min 重发至多 3 次） |
| 0x03 补发 | 补发计数，**不应答**（7 日窗口不拒收） | 应答 `02` |
| 0x04 登出 | 关闭会话，应答 `01`（附录 B 未强制） | 应答 `02` |
| 0x07 心跳 | 应答 `01`（附录 B 未强制） | — |
| 0x08 终端校时 | 上行，数据单元为空，应答 `01` | — |
| 0x05/0x06、0x80 | 方向不符，应答 `02` | — |

### 平台间（正文第 5 章，规范性）

| 上行命令 | 校验正确 | 校验失败 |
|---|---|---|
| 0x05 平台登入 | **应答 `01`** | 应答 `02` |
| 0x06 平台登出 | 应答 `01` | — |
| 0x02 实时 | **应答 `01`**（与车端相反） | 应答 `02` |
| 0x03 补发 | **应答 `01`** | 应答 `02` |
| 车端命令 | 方向不符，应答 `02` | — |

### 应答包构造

附录 B.3.3.2：只变更应答标志与应答报文时间，重新计算校验位，其余报文内容与主动发送报文一致。默认 `ResponseShape::KeepRequestPayload`。

| 形态 | 内容 | 出处 |
|---|---|---|
| `KeepRequestPayload` | 数据单元同请求，前 6 字节换应答时间 | 附录 B（默认） |
| `TimeOnly` | 只保留 6 字节报文时间 | 部分地方标准 |
| `EmptyPayload` | 数据单元为空 | **无条文对应，仅联调** |

应答形态按场景取默认：车端 `KeepRequestPayload`（附录 B），平台间 `TimeOnly`（地方口径）。

缺密钥时：加密帧无法解密，也无法按同加密方式应答，只记录不应答。
