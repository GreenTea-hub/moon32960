# 协议实现对照（GB/T 32960.3-2025）

速查表；完整覆盖与未覆盖项见 [CONFORMANCE.md](CONFORMANCE.md)，案例见 [EXAMPLES.md](EXAMPLES.md)。

## 报文结构

```
[起始符 2B][命令标识 1B][应答标志 1B][唯一识别码 17B][加密方式 1B][数据单元长度 2B 大端][数据单元 NB][校验码 1B]
```

- 起始符：`$$`(0x24) = 2025 版；`##`(0x23) = 2016 年版；
- 校验码：BCC 异或，范围偏移 2 至 23+N；先加密后校验、先校验后解密。

| 车端（表 B.2） | 平台间（表 3） |
|---|---|
| 0x01 车辆登入 | 0x01 车辆登入 |
| 0x02 实时上报 | 0x02 实时上报 |
| 0x03 补发上报 | 0x03 补发上报 |
| 0x04 车辆登出 | 0x04 车辆登出 |

| 0x09 激活 / 0x0A 激活应答（下行） | 0x0C~0x7F 上行预留 |
| 0x0B 密钥交换 | 0x80~0x82 终端预留（下行） |
| 0x80 查询 / 0x81 设置 / 0x82 控制（下行） | 0x83~0xBF 下行预留 |

## 应答标志（表 4）

0x01 成功、0x02 其他错误、0x03 VIN 重复、0x04 VIN 不存在、0x05 验签错误、0x06 数据结构错误、0x07 解密错误、0xFE 命令包。

## 加密方式

0x01 不加密、0x02 RSA、0x03 AES、0x04 SM2、0x05 SM4、0xFE 异常、0xFF 无效。本项目内置 AES，其余识别后拒绝。

## 两套应答规则

| 命令 | 车端（附录 B） | 平台间（第 5 章） |
|---|---|---|
| 0x01 登入 | 应答 01；校验失败忽略不应答 | 应答 01 |
| 0x02 实时 | **正确不应答** | **正确应答 01** |
| 0x03 补发 | 正确不应答 | 正确应答 01 |
| 0x04 登出 / 0x07 心跳 / 0x08 校时 | 应答 01 | 方向不符 |
| 0x80~0x82 下行 | 方向不符 | 方向不符 |

应答包：保留报文时间、删除其余内容、重算校验（6 字节数据单元）。

## 物理换算

车速 ×0.1 km/h（0~5000）；累计里程 ×0.1 km；总电压 ×0.1 V；总电流 ×0.1 A 偏移 −3000 A；绝缘电阻 1 kΩ；单体电压 ×0.001 V；温度 −40 ℃；电机转速 −32000 r/min；电机转矩 ×0.1 N·m 偏移 −20000 N·m；位置 ×10⁻⁶ 度。

异常/无效码：BYTE 0xFE/0xFF、WORD 0xFFFE/0xFFFF、DWORD 0xFFFFFFFE/0xFFFFFFFF，换算函数返回 `None`。
