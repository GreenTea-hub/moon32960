# 协议实现对照

本文件是速查表，完整的覆盖矩阵、兼容性终点与未覆盖项见 [CONFORMANCE.md](CONFORMANCE.md)，三个可复现案例见 [EXAMPLES.md](EXAMPLES.md)。

## 报文结构

```
[起始符 2B "##"][命令单元 1B][应答标志 1B][VIN 17B][加密方式 1B][数据单元长度 2B 大端][数据单元 NB][校验码 1B]
```

- 帧总长 = 24 + N + 1；
- 校验码为 BCC 异或，范围从命令单元首字节到数据单元末字节；
- WORD / DWORD 均为大端。

## 命令单元

| 值 | 语义 | 数据单元 | 实现 |
|---|---|---|---|
| 0x01 | 车辆登入 | 表 6 | `login.mbt` |
| 0x02 | 实时信息上报 | 表 7 | `telemetry.mbt` |
| 0x03 | 补发信息上报 | 同 0x02 | `telemetry.mbt` |
| 0x04 | 车辆登出 | 表 8 | `login.mbt` |
| 0x05 | 平台登入 | 表 9 | `login.mbt` |
| 0x06 | 平台登出 | 登出格式 | 部分 |
| 0x07 | 心跳 | 空 | `login.mbt` |
| 0x08 | 终端校时 | 仅应答 | `gateway.mbt` |
| 0x80 | 平台下行 | 原始负载 | `gateway.mbt` |

## 异常与无效码

| 宽度 | 异常 | 无效 |
|---|---|---|
| BYTE | 0xFE | 0xFF |
| WORD | 0xFFFE | 0xFFFF |
| DWORD | 0xFFFFFFFE | 0xFFFFFFFF |

换算函数遇到异常/无效码返回 `None`，不参与算术。

## 平台处理规则

| 上行命令 | 校验正确 | 校验失败 |
|---|---|---|
| 0x01 登入 | 应答 `01` | 忽略，不应答 |
| 0x01 VIN 重复 | 应答 `03` | — |
| 0x02 实时 | 计数，**不应答** | 应答 `02`，终端 1 分钟重发至多 3 次 |
| 0x03 补发 | 补发计数（7 日窗口），**不应答** | 应答 `02` |
| 0x04 登出 | 关闭会话，应答 `01` | 应答 `02` |
| 0x07 心跳 | 应答 `01` | — |
| 0x08 校时 | 应答 `01` | — |
| 其它 | 应答 `02` | — |

应答包：命令同请求、标志改结果、删数据单元、加密方式回 `01`、重算 BCC。
