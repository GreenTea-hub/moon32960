# 端到端案例（GB/T 32960.3-2025）

```bash
moon run cmd/main -- case login       # 登入与应答（$$ 起始符）
moon run cmd/main -- case encrypted   # AES 加密上报
moon run cmd/main -- case report      # 实时上报：车端不应答
moon run cmd/main -- case resend      # 断线补发
moon run cmd/main -- case platform    # 车端 vs 平台间
```

## 案例一：车辆登入与应答

### ① 终端命令包

```
242401fe4c47574546344135364d463132333435360100251a0b19091e000001383938363036323031383030303132333435363701074241542d413031de
```

| 偏移 | 字节 | 字段 | 取值 |
|---|---|---|---|
| 0 | `24 24` | 起始符 | `$$`，2025 版协议 |
| 2 | `01` | 命令标识 | 车辆登入 |
| 3 | `fe` | 应答标志 | 命令包 |
| 4 | `4c47…3536` | 唯一识别码 | `LGWEF4A56MF123456` |
| 21 | `01` | 加密方式 | 不加密 |
| 22 | `00 25` | 数据单元长度 | 37 |
| 24 | `1a0b19091e00` | 数据采集时间 | 2026-11-25 09:30:00 |
| 30 | `0001` | 登入流水号 | 1 |
| 32 | `3839…3637` | ICCID | `89860620180001234567` |
| 52 | `01` | 储能子系统数 | 1 |
| 53 | `07` | 编码长度 | 7 |
| 54 | `4241542d413031` | 子系统编码 | `BAT-A01` |
| 61 | `de` | 校验码 | BCC(2→60) |

### ② 平台应答

```
242401014c47574546344135364d463132333435360100061a0b19091e003d
```

与请求的差别：

| 字段 | 请求 | 应答 |
|---|---|---|
| 应答标志 | `fe` | `01` 成功 |
| 数据单元长度 | `0025` = 37 | `0006` = 6 |
| 数据单元 | 登入数据 | **只保留 6 字节报文时间** |
| 校验码 | `de` | `3d` |

依据 6.3.2 / B.3.3.2：“变更应答标志，保留报文时间，删除其余报文内容，并重新计算校验位”。

### ③ 重复登入

```
242401034c47574546344135364d463132333435360100061a0b19091e003f
```

应答标志 `03` = VIN 重复（表 4）。

### ④ 校验失败

附录 B.1：平台忽略所接收数据、不回应答。终端 3 分钟超时重发，连续 3 次无应答应间隔 30 分钟重连。

## 案例二：AES 加密上报

密钥：AES-128-ECB `000102030405060708090a0b0c0d0e0f`。

1. 明文数据单元（时间 + 整车 + 位置）；
2. `Telemetry` 编码后按 PKCS#7 填充，AES 加密，加密方式字段置 `03`；
3. BCC 在密文之上计算（先加密后校验）；
4. 平台验 BCC → 解密 → 去填充 → 解析信息体；
5. 车端校验正确**不回应答**；
6. 未注入密钥时无法解密、也无法按同加密方式应答，只记录不应答。

## 案例三：实时上报

车端：

```
平台结论    : report-accepted
说明        : 校验正确，按附录 B.2.1 车端不做应答
应答帧      : 无
```

平台间同一份数据：

```
平台结论    : report-accepted
说明        : 校验正确，按 5.2.2 平台间仍须正确应答 0x01
应答数据单元: 6 字节
```

## 案例四：断线补发

补发帧与实时帧数据单元相同，仅命令标识 `02 → 03`。车端补发同样在正确时不应答；7 日窗口是发送方存储义务，平台不因此拒收。

---

## 案例五：规则对比

1. 车端实时上报：不应答；
2. 平台间实时上报：应答 0x01，数据单元 6 字节；
3. 0x08 终端校时：上行，数据单元为空，应答 0x01；
4. 0x80 查询命令：下行，平台侧判方向不符。
